## 1. BPTT

```python
bptt = BPTT(loss, optimizer=None, checkpoint=None, truncation=None, detach_reset=True)
run = plan.runner(learner=bptt)          # attach: checks + optimizer registration
loss, grads = bptt.grad(duration, xs=None, targets=None)
bptt.step(duration, xs, targets)         # one optimizer step
losses = bptt.fit(duration, n_epochs, xs, targets)   # n_epochs steps in one for_loop
recs = bptt.record(duration, xs)         # what the loss sees
```

* **Episode**: a rollout of the pure `Program.step` from the runner's initial state at
  step 0 (batched runners: `vmap` over trials, `xs` with a leading trial axis).
* **Loss input**: `recordings[observer][recordable]`, shape `(T, n)` (every step,
  observer intervals ignored), mantissas in the observer units.
* **Trainable parameters**: every `ParamState` of the plan — weights of
  `connect(..., trainable=True)` (one per edge group) and neuron parameters of
  `add(..., trainable=(...))`; keys `weights/<proj>/<group>`, `pops/<pop>/<param>`.
  Gradients are w.r.t. mantissas, returned as Quantities in the parameter unit
  (`braintools.optim` expects this).
* **Loop primitives**: the carry is an explicit pytree, so `brainstate.transform.scan`
  / `checkpointed_scan(base=checkpoint)` (AGENTS.md #10: explicit carry → `scan`); the
  spec's `for_loop` wording maps to these. `fit` uses `for_loop` over epochs, all
  inside one `jit`.
* **Truncation** `K`: `stop_gradient` on the carried state at every multiple of `K`
  (forward unchanged).
* **detach_reset**: set on every model at attach (`None` leaves models alone); a spike
  rule's explicit setting still wins.
* **Capability negotiation**: a trainable parameter in, or a trainable projection into,
  a population whose model has `capabilities.differentiable=False` is rejected.
* **Data**: `xs = {population: {port: (T, n)}}` (or `{population: (T, n)}` for a
  single-port population) is added to the port input each step via
  `Program.step(ext=...)`. `ExternalInput` relays data as a float event payload
  (`max_multiplicity=None` → exact float path), so data reaches the network through
  ordinary trainable projections, storages and delays.

## 2. Gate G6 — what "BPTT vs finite differences" means

With a hard forward pass (exact spike counts) and a surrogate backward pass, the BPTT
gradient is **not** the derivative of the simulated loss whenever a gradient flows
through a spike (the true derivative through a spike is 0 a.e.; finite differences see
that). A literal check of surrogate gradients against finite differences therefore
fails by design (measured: relative errors 3–500 on the recurrent nets). G6 is checked
in the two regimes where the two must agree exactly:

1. **Hard forward** (the production pass): feed-forward `ExternalInput → 20` neurons,
   `detach_reset=True`, membrane-MSE loss — no gradient path crosses a spike, so BPTT =
   exact derivative of the piecewise-smooth loss. Trainable: the input weights and
   `tau` / `tau_m`. The nets spike (the gradient crosses resets).
2. **Relaxed forward** (`spiking.relaxed_spikes()`): spikes are the smooth surrogate
   primitive (`surrogate.surrogate_fun`, e.g. `sigmoid(alpha·margin)`) and jumps are
   soft (`s + spike·(jump(s) − s)`). The simulated function is then smooth and its
   exact derivative is what BPTT computes, so the check exercises the spike payload
   VJPs through Dense/CSR storages, delay rings, recurrence and the (non-detached)
   reset. Net: `x → A(10) → B(10)`, `A → A`, all weights + `tau`/`tau_m` trainable,
   `detach_reset=False`, loss = spike-count MSE of `B` + membrane MSE of `A`. The
   float payload path is forced (relaxed spikes are fractional; `BinaryArray`
   binarises).

Both: `LIF` and `iaf_psc_alpha` (default `t_ref`), Dense and CSR, delay 0 and 2 steps,
float64, `Sigmoid` surrogate. Check: one random direction scaled per parameter plus
the largest-gradient coordinate of each parameter, central differences with `ε = 1e-6`,
`|g·v − fd| ≤ 1e-4 |fd|`. Measured errors: 1e-10…2e-5.

## 3. braintrace compatibility (G7)

`check_plan(plan)` (when an `EtraceNetwork` is built): projections with a plasticity
rule (L4: local plasticity + online learning), trainable neuron parameters (braintrace
gives them zero gradient), trainable weights into a model with
`capabilities.etrace=False`, no trainable weight → `EtraceError`.

`check_etrace(module, *x)` traces one step (`StatefulFunction`) and checks:

| rule | detection |
|---|---|
| no `ParamState` writes | write states of the trace |
| ETP primitives not inside `scan`/`while` bodies | recursive jaxpr walk (`braintrace.ETPPrimitive`) |
| every new `HiddenState` value depends on a hidden state (braintrace 0.2.6 `KeyError`) | forward data flow from hidden invars |
| outputs depend on weights only through new hidden values (else silent zero gradients) | taint flow from weight invars, cleared at hidden outvars |
| every trainable `ParamState` is related to a hidden state by a braintrace primitive | `braintrace.find_hidden_param_op_relations_from_module` |

`EtraceNetwork(plan, inputs, outputs)` is the stateful one-step module:
`Program(plan, etrace=True)` (trainable weights through `Storage.forward_etrace`),
model states written back to their `State`s with `new + 0·old` on hidden states,
delay rings as `ShortTermState`s, outputs read from `HiddenState`s.
`Online(algorithm, inputs, outputs, **options)` is the learner:
`plan.runner(learner=Online(...))` builds the module, checks it and
`braintrace.compile`s it (`online.model`). Batched online learning is K1.

G7 test: `x(6) → h(12, recurrent) → o(4)` LIF, Dense and CSR, delay 1 and 2 steps,
`eprop` and `d_rtrl`: compiles, every weight's gradient finite and non-zero; the
one-step module reproduces the runner's spikes and voltages; the checker rejects each
violation (toy modules + a K0 network with raw weights + plan-level cases).

## 4. Edge cases

Batched BPTT equals unbatched for common RNG and identical data; checkpointed
(`base` 2, 4, 16) equals plain to 1e-12; truncation ≥ T equals plain, small
truncation changes gradients but not the loss; per-edge delays give one `ParamState`
per delay group; inputs as Quantities; wrong `xs` shapes/ports/populations; non-scalar
loss; double attach; missing optimizer.

## 5. Limitations / follow-ups

* Episodes always start from the initial state at step 0 (no carried-over state
  between optimizer steps).
* Online learning: delayed inputs are `ShortTermState`s (approximation that the
  diagonal algorithms make anyway); no batching; `Online` exposes the braintrace model
  rather than a training loop.
* With hard spikes and large inputs `LIF` (soft reset, one spike per step) can
  saturate far above threshold, where the `Sigmoid` surrogate gradient underflows to 0
  in float32 — a modelling, not a learner, issue.
