## 1. Positioning

> **brainpy.state is a differentiable point-neuron modeling substrate: the same
> neurons, synapses, plasticity rules, and projections run NEST-validated biological
> simulation *and* train with gradients or online learning — over one `Network` graph
> with written model contracts.**

- **Differentiator.** NEST is trusted but neither differentiable nor JIT-compiled to
  accelerators; SNN-training libraries are differentiable but carry no biological
  validation. brainpy.state aims to be the one substrate that is both
  *NEST-validated* and *end-to-end differentiable under XLA*.
- **Users, in priority order.**
  1. Computational neuroscientists moving NEST models to GPU/TPU, or training them.
  2. Brain-inspired-computing researchers who need biologically constrained SNNs.
  3. BrainX libraries built on top (e.g. `braintrace` for e-prop / online learning).
- **Model scope.** Point neurons only (S1): no multi-compartment and no
  population/mean-field models; no single-unit rate neurons (S1a).
- **One API.** `Network` (populations, projections, devices, observers) compiled to a
  `Plan` and run as a `Program` is the only execution path. The NEST `Simulator`
  vocabulary becomes a thin layer over `Network` (next to K2). The BrainPy-style API
  (standalone modules, AlignPost/AlignPre projections) is **deprecated** (D-e) and
  removed at K4.
- **Non-goals.**
  - Detailed multi-compartment morphology (S1).
  - **MPI** cluster-scale distributed simulation. *In scope:* single-host
    multi-device execution (`shard_map` over the devices of one host; layout specified
    in K1b, prototype in K3).
  - MUSIC / SONATA **co-simulation**. *In scope:* SONATA **import** (network
    description files) and NIR import/export (K3).
  - e-prop and other online-learning algorithms themselves (they live in `braintrace`,
    L1).

## 4. 1.0 criteria

- Frozen public API with a deprecation policy (warnings for ≥ 2 minor releases); the
  BrainPy-style API removed (D-e).
- Every NEST model and every NEST validation test has live-NEST parity **or** a written
  exemption **or** a written removal (S1/S1a), in one inventory.
- Kernel gates (K0–K4) green in CI; > 90 % coverage; docs, doctests and examples run in
  CI.
- Published benchmark report (CPU **and** GPU, measured — no unmeasured claims) and
  migration guide.
