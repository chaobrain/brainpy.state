## 1. Scope

1. One command runs every gate test: `pytest -m k0_gate brainpy_state/_kernel`
   (per gate: `-m k0_g1` … `-m k0_g8`). The gate tests written by T3–T9 are **not
   duplicated**; a registry (`_kernel/validation/gates.py`) lists, per gate, the test
   node-id prefixes that implement it, and `_kernel/conftest.py` attaches the markers at
   collection. New gate tests live in `_kernel/validation/g<k>_*_test.py`.
2. Shared `requires_brian2` marker + skip helper (`_kernel/validation/markers.py`),
   registered in `pyproject.toml`; T8's local skipif switches to it; `brian2` becomes the
   `validation` optional extra.
3. New tests: G1 conductance PSP through the network; G2 Brunel statistics vs NEST; G3
   COBA vs Brian2 (network statistics + single-neuron traces); G4 end-to-end goal-01
   repros through the `Network`.
4. G9 on the remote host (T0 protocol, `benchmarks/brunel_kernel.py`), G10 coverage.
5. Spec updates (G6 row, §9 upstream items, existing-code bugs found) and the K0 report.

### G2 statistics (both simulators, identical definitions, `validation/stats.py`)

Brunel `iaf_psc_alpha`, order 200 (N_E = 800, N_I = 200), NEST `brunel_alpha_nest.py`
parameters, spikes of **all** neurons recorded. A 100 ms initial transient is simulated
and discarded (both sides start every neuron at `V_m = 0`, which gives a synchronous
onset); statistics use the following 1000 ms. 10 seeds each side (NEST `rng_seed`,
kernel `Network(seed)`: connectivity and noise both change with the seed).

- rate E, rate I: spikes / (neurons × 1 s);
- CV-ISI (E): mean over E neurons with >= 3 spikes of `std(ISI) / mean(ISI)`;
- Fano factor (E): spike counts in 10 ms bins, per neuron `var / mean`, mean over E
  neurons with a non-zero mean;
- correlation (E): Pearson correlation of the 10 ms bin counts of the first 50 E
  neurons, mean over pairs with non-zero variance.

### G3 COBA (Vogels & Abbott 2005; the Brian2 `COBA` benchmark)

4000 neurons (3200 E, 800 I), `pairwise_bernoulli(p = 0.02)` without autapses
(Brian2 `connect('i != j', p=0.02)`), `iaf_cond_exp`-equivalent dynamics:
`C_m = 200 pF`, `g_L = 10 nS` (`tau_m = 20 ms`), `E_L = V_reset = -60 mV`,
`V_th = -50 mV`, `t_ref = 5 ms`, `I_e = 200 pA` (Brian2's `I = 20 mV` drive),
`tau_ex = 5 ms`, `tau_in = 10 ms`, `E_ex = 0 mV`, `E_in = -80 mV`, `Δg_ex = 6 nS`,
`Δg_in = 67 nS`, delay `dt` (Brian2 `delay = 0.1 ms`; a recurrent network needs >= 1
step in the kernel), initial `V ~ U(V_reset, V_th)`. Brian2 integrates with `rk4` at
`dt = 0.1 ms`, and its threshold/reset/refractoriness are made to match NEST's
`iaf_cond_exp` (threshold checked after the step, `V` clamped while refractory).
Statistics as G2 (no transient discarded: the initial voltages are random) over
1000 ms. Single neuron: identical input spike trains into one neuron on both sides,
`V_m`, `g_ex`, `g_in` traces `CAT_A`, spike times equal.

### G6 interpretation (accepted by the orchestrator, see T9 spec)

Central finite differences are only a valid reference where BPTT computes the exact
derivative of a smooth function: (a) hard forward, feed-forward net, `detach_reset=True`,
membrane loss; (b) `relaxed_spikes()` (smooth spikes and soft jumps) on recurrent nets.

## 3. Performance work allowed by the task (contained in `_kernel`, with tests)

- Storage structure arrays (CSR `indices`, gather `rows`, Dense `mask`) are passed to
  the compiled runner as **arguments** (`Storage.arrays()` / `Storage.bound()`,
  `Program.structure()` / `Program.bound()`), not closed over: closed-over arrays were
  embedded as HLO constants (compile time and memory proportional to the edges).
- Host index copies in storages are int32 when they fit; `CSR._order_j` is built on
  demand.
- CSR gather path when `n_edges <= max(n_pre, n_post)` (e.g. `one_to_one`), `payload * w`
  for the identity map — T5's "diagonal fast path" follow-up.
- `poisson_counts`: CDF inversion (one uniform per unit) for `lam < 10` instead of
  Knuth's `count + 1` uniforms; still exact in distribution (chi-square tested), no
  longer bit-identical to `jax.random.poisson` (which stays the `lam >= 10` branch).

## 4. Edge cases covered

Structure binding restores the arrays on error; braintrace templates stay concrete;
gather path with multapses / several sources per target / batched / vmap / gradients;
Poisson `lam = 0`, heterogeneous `lam`, tail beyond the unrolled terms, x64 invariance;
G4 delivery on slices, overlapping slices and concatenations with Dense and CSR; G2/G3
statistics on silent neurons (excluded per definition).
