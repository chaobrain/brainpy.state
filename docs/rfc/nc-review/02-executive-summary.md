# Executive Summary

> Part of the editorial report on [`../network-spec-dsl/`](../network-spec-dsl/). See [README](./README.md) for navigation.

The manuscript specifies a frozen, content-hashable intermediate representation (`NetIR`) for spiking neural networks, with two equivalent frontends (a fluent Python builder and a YAML/JSON data DSL) and three backend families (simulation, training, export). The design is **engineering-mature**: a comprehensive validation catalog (`SPEC-NNN` / `EXPORT-NIR-NNN`), backend capability protocol, NIR export with a six-class lossiness taxonomy and an `nir.brainx.*` extension namespace, build-time variables (`net.variable` / `VariableRef`) for sweeps and A/B comparisons, an end-to-end determinism contract over `(NetIR, variables, backend, seed, dt)`, six concentric layers of plasticity expressiveness, explicit modulator-graph signals, schedule grammar for experiment protocols, and DAG composability with temporal-offset semantics.

The load-bearing **novelty claim**, articulated in §1.1, is that the same network description drives four mathematically distinct SNN training paradigms — BPTT (with surrogate gradients), event-prop (Wunderlich & Pehle 2021), RTRL / forward-mode autodiff, and eligibility-trace methods (e-prop, Bellec 2020) — from a single IR. Every existing SNN framework commits to one training paradigm at model-definition time; this proposal positions itself as the empty quadrant on the prior-art map. The framing is the right one and the design choices (immutable IR, declared build-time variables, paradigm-neutral spec module, backends as peer top-level modules under `brainpy.state`) preserve neutrality across the four paradigms.

As a *research contribution* the work suffers from two strategic deficits. First, the novelty claim is **expressively supported but not mechanically demonstrated**: the IR ships no marker that distinguishes which training paradigm a given network admits, the per-shipped-training-backend capability matrix is not written out in §5, and no worked comparative-study benchmark accompanies the spec. Second, the **prior-art engagement in §1.1 is still narrow**: NeuroML / LEMS, SONATA, NMODL / NESTML, NIR-as-competing-upstream-IR, EXODUS, hxtorch.snn, and Lava-DL multi-paradigm coverage are not engaged.

The work is publication-worthy as a *systems / methods* contribution at the *Neuroinformatics* / *Frontiers in Neuroinformatics* / *JOSS* / *SoftwareX* tier as it stands. For *Nature Communications*, it needs (a) `G13` traced through the IR, (b) per-shipped-backend capabilities written out, (c) one published comparative-study result reproduced by switching the backend on a single IR, and (d) the broader prior-art engagement.
